# Host-install switches, image helper, self-test (series 0.4)

Converted from the archived decision log ([[docs/graph/261111230000-D005|converted archive decisions]]): `docs/archive/design/process/05-decisions.md` line 581, D-020 (accepted (implementation: 0/4/0)).

## Context

Hermes needed a login shell (bnox thing users get `nologin`; its terminal tool died — G33) and nix-ld with its variables in the unit (prebuilt glibc binaries — G26). gsheet's bare dockerTools image lacked `/etc/passwd`, `HOME` and a CA store (G18/G19/G30; the last only surfaced on the first live call). agenthub's `agenthub-validate` proves broker permissions by publishing as each identity.

## Decision

1. **Host-install switches in `.bnox/`:** `shell = true` (thing user gets bash) and `nixLd = true` (nix-ld enabled + `NIX_LD`/`NIX_LD_LIBRARY_PATH` set in the unit). Both default off; host-install only. These enable the thing to work — control stays in NATS/egress/inbound.
2. **`bnox.lib.mkImage`:** an image helper that always bakes a root `/etc/passwd`, `HOME`, and CA certificates; things use it instead of bare dockerTools.
3. **`bnox-validate`:** generated from the computed NATS permission matrix ([[docs/graph/261111230018-R018|NATS identity: logins always, two-level permissions, roles (series 0.4)]]), tests every grant and every denial at the broker; later extended to egress/inbound. Part of the done rule ([[docs/graph/261111230017-R017|bnox-bg lessons, fix batch (series 0.3, patch 0/3/1)]] §6).
4. **Docs notes:** host repos pin bnox's nixpkgs explicitly (`follows`); `nixos-rebuild` may exit 4 when a NATS auth change restarts the broker mid-switch (G59) — check `systemctl is-active` after a few seconds.
