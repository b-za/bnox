# Project name

Converted from the archived decision log ([[docs/graph/261111230000-D005|converted archive decisions]]): `docs/archive/design/process/05-decisions.md` line 24, D-001 (accepted).

## Context

Working name was `baseos`. Needed a real name before locking the directory and flake name (Q1). Wanted something short, OS-flavoured, personal, and collision-free.

## Decision

**`bnox`** — bh + nox (nix + night). Short, ends in OS-adjacent sound, distinctive.

## Alternatives Considered

`baseos` (placeholder, generic), `noxos` (taken — active NoxOS-org on GitHub), `snowi-os` (too tied to one host), `bhos`, `keystone`, `rootstockos`, `nyxos`. Collision check ruled out `noxos`. `bnox` GitHub search returns only 8 weak results (file organizer, dormant crypto token, IMU sensor part number BNOx) — none in the OS / Nix space.
