# Adopt sebig in bnox: design/ is archived, the corpus lives in docs/graph

## Decision

bnox adopts sebig 0.0.4 (installed from `/Users/bh/repos/sebig`), the way bnox-bg did. Layout: `AGENTS.md` + a one-line `CLAUDE.md` pointing at it; the immutable base in `.sebig/`; `tools/` linking into it per file plus bnox's own files in `tools/meta/`; the corpus in `docs/graph/`. The former `design/` workspace (process docs, decision log D-001..D-021, jobs, STATUS, changelog) moves unchanged to `docs/archive/design/` (git mv, history kept). This replaces D-014 §6 ("repo root = README + design/ + versions/ only") — [[docs/graph/261111230014-R014|Host-repo split + versioned bnox product]]. The product (`versions/`) and its consumer docs (`versions/<maj>/<min>/docs/`) are untouched: sebig is for working on bnox, not for using it.
