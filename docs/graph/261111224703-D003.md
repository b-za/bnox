# bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands

## Decision

bnox starts from bnox-bg's adaptations of sebig 0.0.4 as its own local copies: the Spec Authoring Guide (`tools/meta/260825144541-DFTS.md`), the Agent Boot Guide (`260831200000-EGOA.md`) and the Boot Set (`260829153015-EFGV.md`), reworded for bnox, plus bnox-bg's general local rules in [[tools/meta/261111224800-H001|bnox local hows]]. When bnox-bg's general rule changes land in sebig itself as 0.0.5, a reconciliation check runs ([[docs/graph/261111224902-J002|Reconcile bnox's local sebig copies with sebig 0.0.5]]): upgrade bnox, then drop every local copy and rule 0.0.5 covers.

Inherited bnox-bg decisions (their notes live in `../bnox-bg/docs/graph/`; the copies in `tools/meta` cite them by id):

| bnox-bg | Rule |
|---|---|
| D003 | CLAUDE.md points agents at AGENTS.md |
| D005 | Handovers are recorded in the session note; the prompt points into the corpus; ask first |
| D008 | What counts as a decision |
| D009 | Only explicit rulings are ruled-by-person |
| D010 | Alternative and trigger notes only when they really exist |
| D011 | decision-how / decision-corpus note types and judgement-by-agent |
| D012 | Superseding is recorded with two-way links plus a stale-reference check |
| D013 | Frontmatter: aliases; tags hold subject words only; typed authority/status/priority/severity/category |
| D014 | "No work until we are done talking" means discussion only |
| D034 | Counts rule narrowed to claims about current state |
| D035 | Two domains, carried by the type suffix: how we work / what we are working on |
| D036 | Operational hows live in tools/; the decisions behind them live in docs/graph |
| D037 | tools/ is linked per file; deviating from a shipped how replaces its link with a real file |
| D038 | On a sebig upgrade, every overridden file is reviewed with the person |
| D039 | Adaptations of sebig rules belong in the sebig base |
| D040 | The base's spec-splitting guidance is the norm; deviations are explicit user choices |
| D042 | Variable tokens in subjects are named placeholders |
| D043 | Drop CLI commands that do not exist; ask sebig for the missing tooling |
| D044 | The Agent Boot Guide is repo-neutral; the repo uses its own copy (never run boot-guide-generate) |
| D045 | The boot set lists only files that exist; read policy by note type |
| D046 | Close-out records each new decision's supersession search |

Not inherited (bnox-bg-specific): D006 (gsheet stage pivot), D041 (bnox-bg's spec split), its rules 12–13 (gsheet stage work and handover content). bnox has no repo-specific spec split yet.
