# tools/ links are relative

## Decision

`tools/checks`, `tools/scripts` and the linked `tools/meta` files point into `.sebig/` with relative symlinks. The sebig 0.0.4 installer writes absolute links (`/Users/bh/...`), which break in any other checkout — the same fix bnox-bg made (its commit b24182c).

## Alternatives Considered

None — no alternative was raised.

## Losing Readings

No alternative was raised.

None.
