# No hows or corpus change without an explicit 🅑 decision

🅑 2026-09-04. A standing governance rule for every agent, current and future.

## Decision

The repository has two domains:

| Domain | Location | What it is |
|--------|----------|------------|
| **hows** (meta-procedure) | `tools/meta/`, `tools/scripts/`, `tools/checks/` | **How we work** — protocols, guides, checks, boot set, scripts |
| **corpus** (subject-matter) | `docs/graph/` | **What we're working on** — decisions, specs, concepts, narratives, contracts, runbooks |

1. **Agents follow the repo's hows** — the boot set, the reading list, the guides, the protocols, the checks, the scripts, the checklists. Follow them; ⛔ do ⛔ not improvise around them or invent substitutes. **The agent protects the hows and the corpus** — from drift and from un-decisioned change.

2. **⛔ No hows change ⛔ and ⛔ no corpus change without an explicit 🅑 decision.** When 🅑 says something that would change a how or the corpus, the agent must ⛔ **surface the deviation before making the change** — *"this is different from what we have — is this a decision to change it?"* — and only on his confirmation make the change, recorded as a `decision-how` (hows change) or `decision-corpus` (corpus change). ⛔ A passing remark is ⛔ not a change order; it must become an explicit decision first. The decision note is the mechanism that authorises and records the change.

3. **When 🅑 names a note type that does not exist** (e.g. a *"process note"*), the agent must ⛔ **say so and map the intent to the real home** — *"there is no \`process\` note; the hows are \`protocol\` (prescriptive workflow), \`guide\` (explanatory), \`check\` (verification), \`script\` (deterministic). The corpus has \`decision-corpus\`, \`spec\`, \`concept\`, etc. — which home fits the intent?"* — and propose that home. ⛔ Do ⛔ not invent a new type to match the words; map to what exists.

## Losing Readings

- **Execute 🅑's words as-is** — lost: silent drift, hows/corpus changes with no decision behind them, and invented structure (a "process note" that is not one of the real types).
- **Guess a home for his intent** — lost: manufacturing a new note type when an existing one fits.

## Consequences

- Wired into the boot surface (\`AGENTS.md\` + the reading list) so every future agent reads it at boot.
- Every hows/corpus change's trail ends in a \`decision-how\` / \`decision-corpus\` note that 🅑 confirmed ⛔ before it landed.
