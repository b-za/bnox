procedure: |
  1. Check if counts.json exists at repo root
  2. If exists: validate JSON structure (generated_at, notes_total, by_type, by_tag, links)
  3. Search corpus for hardcoded counts:
     - grep -rn "notes total" docs/ tools/
     - grep -rn "[0-9]\+ notes" docs/ tools/
     - grep -rn "[0-9]\+ decisions" docs/ tools/
     - grep -rn "total.*:" docs/ tools/ | grep -v "generated_at"
  4. For each hardcoded count: verify it matches counts.json or is in a generated fence
  5. Report: file, hardcoded_value, counts_json_value, in_fence (yes/no)

what_to_look_for:
  - Counts in authored prose (not in GENERATED fence)
  - counts.json missing or malformed
  - Stale counts.json (generated_at older than newest note)

pass_fail_criteria: |
  PASS: counts.json exists and valid, zero hardcoded counts in authored prose.
  FAIL: counts.json missing, or any hardcoded count outside GENERATED fence.
