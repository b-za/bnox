procedure: |
  1. Run `generated-fence-check` script
  2. For each file with GENERATED fences:
     a. Verify START/END pairs match (same ID)
     b. Verify fence IDs unique across corpus
     c. Verify content between fences is machine-generated (no hand edits)
     d. Verify no GENERATED fences in non-index files (unless hybrid)
  3. Report: file, fence_id, pair_match (yes/no), unique (yes/no), clean (yes/no)

what_to_look_for:
  - Mismatched START/END IDs
  - Duplicate fence IDs across files
  - Hand-edited content between fences
  - GENERATED fences in files without hybrid note structure

pass_fail_criteria: |
  PASS: All fences paired, unique IDs, clean separation.
  FAIL: Any mismatch, duplicate, or contamination.
  Output: List of (file, fence_id, status)
