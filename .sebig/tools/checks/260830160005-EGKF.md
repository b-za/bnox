alias:
  - "Verify measurement instrument"
  - "Measurement instrument check"
tags:
  - "check"
  - "verification"
  - "meta-procedure"
implements: ["260825144541-DFTS"]
procedure: |
  1. Search corpus for measurement claims:
     - grep -r "counted by" docs/ tools/
     - grep -r "measured by" docs/ tools/
     - grep -r "[0-9]+" docs/ | grep -v "id:" | grep -v "date:"

  2. For each measurement found:
     a. Extract the claim (e.g., "99 notes", "245 links")
     b. Verify instrument stated (grep command, script name, tool)
     c. Run the instrument to verify current value
     d. Check if count is in separate file (counts.json) not in corpus

  3. Report: file, claim, instrument, verified_value, match (yes/no)

what_to_look_for:
  - Bare numbers without instrument ("there are 99 notes")
  - Instrument stated but not runnable ("counted by manual review")
  - Counts embedded in corpus files (should be in counts.json)
  - Stale measurements (instrument gives different value now)

pass_fail_criteria: |
  PASS: Every measurement states instrument, instrument runs, value matches (or staleness noted).
  FAIL: Any measurement lacks instrument, instrument fails, or count in corpus not counts.json.
  Output: List of (file, claim, instrument, current_value, match)
