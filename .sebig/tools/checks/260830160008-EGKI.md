id: "260830160008-EGKI"
type: "check"
alias:
  - "Verify no authored overwrite"
  - "Generator authored content protection"
tags:
  - "check"
  - "verification"
  - "meta-procedure"
implements: ["260825144541-DFTS"]
procedure: |
  1. For each generator script in tools/scripts/:
     a. Identify its target file(s) and fence ID(s)
     b. Run generator with --output-path to temp file
     c. Compare temp output with current file content between fences
     d. Verify content OUTSIDE fences unchanged
  2. Check for generator patterns that write outside fences:
     - grep -r "sed.*>.*\.md" tools/scripts/
     - grep -r "awk.*>.*\.md" tools/scripts/
     - grep -r "cat.*>.*\.md" tools/scripts/
  3. Report: script, target_file, outside_fence_changed (yes/no)

what_to_look_for:
  - Generators using shell redirection (> file) instead of fence-aware write
  - Target file modified outside fence boundaries
  - Generator that exits if fence missing (correct) vs overwrites entire file

pass_fail_criteria: |
  PASS: All generators only modify content between their designated fences.
  FAIL: Any generator modifies authored content outside fences.
  Output: List of (script, target_file, outside_fence_changed)
