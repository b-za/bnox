## Session Protocol

1. **Entry:** Read this boot set
2. **Work:** Follow the read policy; capture decisions at the moment of agreement
3. **Close-out:** Run the close-out checklist:
   1. Every decision captured with losing readings (alternatives/triggers only when real)
   2. Context sweep — enumerate conflicts, judgement calls, deferred options, stale notes
   3. State notes still true
   4. Index entries regenerated (project-index, hows-index)
   5. Audit what the indexes don't point at
   6. Re-measure anything reported as current state
   7. Did today's decisions invalidate today's findings?
   8. Did every decision reach its destination (a how in tools/, a spec, a contract)?
   9. Record each new decision's supersession search in the session note
   10. **Is there anything important only in the current context that future agents need to know?**
   11. **Log any findings** — `finding-how` / `finding-corpus` notes
4. **Handover:** Record it in the session note (order of attack for the next agent); ask the person before writing it, then give a short prompt in the conversation pointing at `AGENTS.md` and the session note

## Context Sweep Procedure

The context sweep is the step that catches what the other checks miss. Other steps test *file state*; this one tests *the agent*.

**Enumerate out loud, walking fixed categories:**

- Conflicts you noticed but did not raise
- Judgement calls you made silently
- Things you deliberately did not do, and why
- Options you set aside
- Notes that went stale under you
- Catch-all: *if you were asked "anything else on your mind?", what would you say?*

**Stopping rule:** After a pass, ask whether anything has happened *since* it — a ruling, an edit, a measurement. Yes → run another pass over just that; no → stop and **say** you stopped.

## Boot Prompt Rule

When creating boot prompts (or any document that references conventions):

1. **Read the decision files first** — extract IDs, do not rely on memory
2. **Write only references** — file IDs and reading order only
3. **Never include convention summaries** — no tables, definitions, "quick references", or "key conventions" sections
4. **Decision files and hows ARE the conventions** — boot prompts contain only file IDs and reading order
