# bnox local hows

How this repository works where the shipped sebig hows say nothing. Where bnox differs from a shipped how, that how is replaced by a real copy in `tools/meta` with its changes listed at the top (today: the Spec Authoring Guide, the Agent Boot Guide and the Boot Set, all inherited from bnox-bg — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]]).

## Rules

1. The former design workspace lives in `docs/archive/design/` (referenced by path, not corpus) — [[docs/graph/261111224701-D001|Adopt sebig in bnox: design/ is archived, the corpus lives in docs/graph]]
2. `CLAUDE.md` points agents at `AGENTS.md` — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D003)
3. Handovers are recorded in the session note; ask the person first, then give a short prompt in the conversation — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D005)
4. "No work until we are done talking" means discussion only — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D014)
5. Deviating from a shipped how replaces its link with a real file linked to its decision — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D037)
6. At a sebig upgrade, every replaced file is reviewed with the person — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D038)
7. Adaptations of sebig rules are taken to the sebig base; overrides are reverted when it adopts them — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D039); next: [[docs/graph/261111224902-J002|Reconcile bnox's local sebig copies with sebig 0.0.5]]
8. Close-out records each new decision's supersession search — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D046)
9. Never run `tools/scripts/boot-guide-generate` here — [[docs/graph/261111224703-D003|bnox starts from bnox-bg's sebig adaptations; reconcile when sebig 0.0.5 lands]] (bnox-bg D044)
10. `tools/` links into `.sebig/` are relative — [[docs/graph/261111224704-D004|tools/ links are relative]]
11. bnox's own process rules still apply alongside sebig: a version is `done` only after a real deploy and `bnox-validate` (archived D-017 §6); fixes are never copied back into a frozen version (series docs, `versions/*/docs/versioning.md`).

## What This Does Not Do

- Does not repeat the shipped hows or the changes in the replaced copies; read those files.
- Does not override anything not listed here.
